**SCC Homes**

**About**

A **Java console** prototype for managing a residential community. Users can sign up, log in, and access features based on their role. The system 

supports Homeowners, Property Managers, and Security Personnel.

Homeowners can view their information, manage maintenance fees, make payments, and register visitors. Property Managers can manage homeowners, 

community fees, dues, payments, and visitor records. Security Personnel can verify visitors and record visitor entry, exit, and access logs.

**How to Run**

• Download or clone the repository.

• Open the project using a Java IDE such as IntelliJ IDEA.

• Open the src folder.

• Run Main.java.

• The system will open in the console.

**How to Use**

• From the main menu, choose Sign Up to create an account.

• Choose Login and enter your email and password.

• Homeowner: view your information, check maintenance fees, pay fees, register visitors, and view your registered visitors.

• Property Manager: view and manage homeowners, view dues, set community fees, view payment history, and manage visitor records and access logs.

• Security Personnel: view pending visitors, verify visitors, record visitor entry and exit, and view access logs.

The system identifies the user's role based on the email entered during login. Emails containing admin are treated as Property Manager accounts,

emails containing security are treated as Security Personnel accounts, and other emails are treated as Homeowner accounts.

**Note**

This is a prototype for educational purposes. Some features are currently represented by placeholder sections and may require further 

implementation. User and account information is currently handled while the program is running and is not permanently stored.
